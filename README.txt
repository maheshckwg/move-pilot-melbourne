MOVE PILOT MELBOURNE CLEAN V7 — ASSIGN STAFF

Adds Admin staff assignment:
- Admin taps Assign Staff on a Needs Staff job
- Select exactly which staff members should receive the offer
- Shows availability and existing offer status
- Selected staff receive the offer
- Unselected previous offers are cancelled
- Accepted staff remain accepted
- Dashboard shows assigned staff names
- Once enough staff accept, the existing secure RPC automatically confirms the job

No new SQL required.
