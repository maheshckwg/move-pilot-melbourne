MOVE PILOT MELBOURNE - CLEAN V4

Adds full van visibility and handover workflow:
- Add first van from the Van tab
- Edit van details
- Vehicle name, registration, current KM, rego, insurance, service date and notes
- Assign a van when creating or editing a job
- Staff can see active vehicle details
- Job Operations shows the assigned van
- Van & key base is fixed/displayed as 62 Duncombe Ave
- Staff collect van + keys from 62 Duncombe Ave before the job
- Before KM + before photos recorded
- Job starts after collection
- After KM + after photos recorded
- Staff return van + keys to 62 Duncombe Ave
- Job completion is tied to the return record
- Vehicle current KM updates from the final KM after return

No new Supabase SQL required. The clean V1 database schema already supports these records.
